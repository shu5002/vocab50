ステップ0：このアプリのHTMLコードを取得

下のボタンを押すと、このアプリ全体の完全なHTMLコード（index.html）をワンタップでコピーまたはダウンロードできます。

ステップ1：GitHub Pagesに置く（3分）

  1. GitHubで新規リポジトリ（例: vocab50）を作成
  2. Add file ＞ Create new file を選択
  3. ファイル名を index.html にし、コピーしたHTMLを貼り付けて Commit changes
  4. Settings ＞ Pages を開き、Branchを main にして Save
  5. 発行されたURL（https://ユーザー名.github.io/vocab50/）をiPhoneのSafariで開く

ステップ2：Safariからホーム画面に追加

  1. Safari画面下の「共有ボタン（四角から上矢印）」をタップ
  2. 「ホーム画面に追加」をタップ
  3. ホーム画面に専用の「50 VOCAB」アイコンが追加され、毎日1タップ・0秒で起動できます！
